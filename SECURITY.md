# Security policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** option in the repository's **Security** tab to send a private report if private vulnerability reporting is enabled.

Private vulnerability reporting is not currently confirmed as enabled. If the option is unavailable, contact the repository owner privately through GitHub rather than posting exploit details publicly. Include affected versions or commits, impact, and concise reproduction details. Avoid including real user data or secrets.

The maintainers will acknowledge reports when possible, investigate privately, and coordinate remediation and disclosure with the reporter. There is no guaranteed response time or published security advisory process yet.

## Supported versions

No FEMS application release has been published, so there are no released versions with defined security support at this time. Report issues affecting the current `main` branch through the private route above.
