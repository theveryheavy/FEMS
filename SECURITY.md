# Security policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue. Private vulnerability reporting is enabled for this repository. Use GitHub's **Report a vulnerability** option in the repository's **Security** tab to send a private report. Include affected versions or commits, impact, and concise reproduction details. Avoid including real user data or secrets.

We'll review reports privately and work with the reporter on a fix and disclosure. We don't have a guaranteed response time.

## Supported versions

No FEMS application release has been published, so there are no released versions with defined security support at this time. Report issues affecting the current `main` branch through the private route above.
