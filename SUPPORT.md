# Support

FEMS isn't available to download yet. Mod listings are submitted through pull requests to `mods/`.

- **Something broken?** Use the [bug report form](https://github.com/theveryheavy/FEMS/issues/new?template=bug-report.yml). Include your Windows version and FEMS version or commit, if applicable.
- **Have an idea?** Use the [feature request form](https://github.com/theveryheavy/FEMS/issues/new?template=feature-request.yml).
- **Submitting a mod?** Open a pull request and follow the [mod listing guide](mods/README.md).
- **Question or listing report?** Use [GitHub Discussions](https://github.com/theveryheavy/FEMS/discussions) for questions. Use the [mod catalog issue form](https://github.com/theveryheavy/FEMS/issues/new?template=mod-submission.yml) to report a broken or potentially malicious listing.
- **Security issue?** Follow [SECURITY.md](SECURITY.md) and report it privately.

Remove passwords, tokens, and personal information before sharing logs.
