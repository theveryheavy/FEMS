## Release process

FEMS will use Semantic Versioning (`MAJOR.MINOR.PATCH`). A maintainer will prepare and publish each release deliberately; nothing is released automatically.

Release notes should cover new features, improvements, bug fixes, and breaking changes. Prereleases should use a version suffix such as `-rc.1` and be marked as prereleases on GitHub. No release, tag, or executable has been published.
